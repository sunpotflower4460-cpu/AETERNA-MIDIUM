# AETERNA Purification Charter

This charter fixes the Phase 0 reading of AETERNA.

AETERNA is **not** a device that assigns meaning. It is a **torus-shaped, life-like field** that may sustain conditions from which structured meaning could later emerge. In this phase, AETERNA is treated as a **pre-semantic vessel**: a place where ongoingness, perturbation, mismatch, recovery, residue, and recurrence can persist before any semantic interpretation is attempted.

## Phase 0 Priority

- Fix AETERNA's role before adding new functions
- Fix implementation boundaries before extending bridges
- Fix observation vocabulary before reusing runtime outputs as meaning
- Prefer documentation and boundary clarity over feature growth

## Definition

AETERNA is:

- a torus field that persists as a life-like substrate
- a vessel prior to meaning
- a runtime for baseline flow, perturbation, prediction, recovery, and recurrence
- a field that may produce observable patterns without claiming what they mean

AETERNA is not:

- a semantic dictionary
- a conversation AI
- a label assignment device
- a teacher-bound interpretation layer

## What Must Remain Inside AETERNA

The following are part of AETERNA from the start:

- baseline flow
- local propagation
- perturbation reception
- prediction / mismatch
- recovery / relaxation
- boundary
- residue
- replay
- self-preservation
- long-cycle drift

These belong to the organism field itself and remain valid even when no semantic account is attached to them.

## What Must Not Be Built Into AETERNA by Default

The following do **not** belong to AETERNA's core role in Phase 0:

- semantic node
- object label
- category
- same-object detection
- teacher binding
- natural language meaning
- emotional persona
- narrative

If later layers use such structures, they must remain explicitly outside the AETERNA core boundary.

## Observation Vocabulary Inside AETERNA

Patterns observed in AETERNA should be described with pre-semantic observation vocabulary such as:

- knot
- path
- recurrence locus
- basin
- collapse profile
- recovery profile
- long-lived anomaly
- proto-point candidate

These terms describe observable organization, not semantic truth. They should not be read as proof of objecthood, concept formation, or language meaning.

## AETERNA / Node Responsibility Boundary

- **AETERNA** = pre-semantic life field
- **Node** = layer that may later structure what emerged

AETERNA may return persistent patterns, tensions, recurrences, and candidates for later structuring. Node-side systems may decide whether any of those patterns deserve labeling, grouping, or interpretation. That structuring step is **not** part of AETERNA itself.

## Naming Guardrail

Some existing names in code or docs may sound more semantic than intended. In Phase 0, such names must be read as:

- convenience names
- observer-side shorthand
- non-semantic claims

Existing implementation presence must not be misread as proof that semantic responsibility belongs to AETERNA.
