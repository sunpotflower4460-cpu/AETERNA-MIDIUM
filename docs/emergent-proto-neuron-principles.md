# Emergent Proto-Neuron Principles

## proto-neuron とは

proto-neuron は、最初から置かれるノードではない。
トーラス生命場の流れの中で自然に観測される、発火性のある局所的な節候補である。

proto-neuron は以下ではない。

- semantic node
- object label
- concept
- same-object detection
- teacher binding
- memory item
- language meaning

## proto-neuron の前段階

```
flow
↓
excitable region
↓
trace
↓
recurrence
↓
co-activation
↓
proto-neuron candidate
↓
proto-network candidate
```

## proto-neuron candidate の条件

### excitability（発火性）
局所領域が発火しやすい状態にある。

### refractory-like behavior（不応期的挙動）
発火後、すぐ再発火しすぎない。持続するが過剰にならない。

### local propagation（局所伝播）
近傍へ影響を伝える。ただし全体を支配しない。

### trace retention（痕跡保持）
発火後に痕跡が残る。トレースとして再利用される。

### recurrence（再発性）
似た条件が揃うと再び発火する。

### co-activation（共起活性化）
他の候補と一緒に立ち上がる。将来の proto-network の萌芽。

### weak plasticity（弱い可塑性）
何度も一緒に起きた流路が、少し通りやすくなる。意味の付与ではなく構造的変化。

## 観測の原則

- proto-neuron candidate は observer-side の候補であり、organism core に直接フィードバックされない
- 候補の検出はトーラス生命場の流れから自然に行われる。先に配置しない。
- 候補は研究上の観測記録であり、意味を付与してはならない
- Node bridge（Node-AI-Z / Node Mother）への接続は後段（W7 以降）で検討する

## 禁止事項

以下を proto-neuron と称して追加してはならない。

- 意味を持つノード
- オブジェクトのラベル
- コンセプト識別子
- 教師ラベルからの binding
- LLM 的な意味付け

## このフェーズ（W0）での位置づけ

W0 では proto-neuron の実装は行わない。
W7（Emergent Proto-Neuron Observation）で観測を開始する。

この文書は、将来の観測が「意味ノードの配置」に誤解されないための原則を固定するものである。
