# Arousal / Awareness-like Availability Principles

AETERNA v0.5 / A2 separates activity height from foreground availability.

## Core Distinction

- **arousalLevel**: how activated / mobilized the organism is
- **awarenessWindow**: how available the organism is for foreground formation
- **salienceOpenness**: how easily novelty / mismatch can pass through that window
- **foregroundPressure**: how strongly something is currently pressing toward foreground

These are **not** a human consciousness model.

## Why Separate Them

If activity height and foreground availability are collapsed into one value:

- overload can look falsely "clear"
- quiet states can look falsely "closed"
- later minimal-self and uncertainty work loses an important distinction

The A2 split keeps these cases visible:

- high arousal + low awarenessWindow
- moderate arousal + stable awarenessWindow
- low arousal + thin awarenessWindow
- low arousal + stable awarenessWindow

## Source Mapping

### arousalLevel

Derived mainly from:

- current activity / firing summary
- ignition ratio
- overload
- perturbation load
- recent touch surprise
- prediction sensitivity
- world pressure

### awarenessWindow

Derived mainly from:

- felt coherence
- boundary integrity
- restoration readiness
- self continuity
- relation engagement
- coherence memory

Reduced mainly by:

- overload
- depletion
- perturbation load
- recent touch surprise
- world pressure

### salienceOpenness

Derived from:

- awarenessWindow
- openness
- perturbation load
- recent touch surprise
- prediction sensitivity

Reduced by:

- depletion
- overload

### foregroundPressure

Derived from:

- perturbation load
- recent touch surprise
- overload
- continuity loss
- depletion
- touch activity passing through relation engagement

## Metric Status

- **Exact**: none of the A2 values are direct measurements
- **Derived**: `arousalLevel`, `awarenessWindow`, `salienceOpenness`, `foregroundPressure`, `restDepth`, `hyperreactivity`, `settlingWindow`
- **Proxy**: none of the A2 values claim a human awareness or consciousness construct

## Relationship to Existing Systems

### Felt-state

A2 is built on A1 felt-state and remains downstream from it.

### Mode

A2 does **not** directly switch mode.
Mode remains governed by existing wake/sleep/dream pressures.

### Beautiful Loop L3 modulation

In this phase the new A2 state is primarily observational.
It is exposed to runtime/scenario/observer paths without becoming a primary driver.

## What Is Deferred

Left for A3 / A4 / later B phases:

- uncertainty-layer integration
- minimal-self expansion
- stronger attentional gating
- self-report or narrative coupling
- any human-style consciousness interpretation
