# Experiment Artifacts

This directory contains outputs from experimental scenario runs.

## Structure

Each experiment run may produce:
- JSON files with full metrics data
- Summary text files
- Config files for reproducibility

## Naming Convention

`[scenario-name]-[timestamp].json`
`[scenario-name]-[timestamp]-summary.txt`

## Usage

Results are generated by `runScenario()` and can be exported via `exportScenarioJSON()`.

Example:
```typescript
import { runScenario, exportScenarioJSON } from '../src/experiments/runScenario';

const result = runScenario({ name: 'test', totalFrames: 1000 });
const json = exportScenarioJSON(result);
// Write to artifacts/experiments/test-[timestamp].json
```
